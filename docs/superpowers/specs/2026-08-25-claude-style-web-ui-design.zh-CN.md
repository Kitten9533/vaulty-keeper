## 目标

为现有加密 Apollo 快照工作流增加本地 Web UI，方便人工管理；不替代 CLI，后者继续承担脚本和自动化接口。

## 范围

首版只覆盖快照管理：

- 列出可用快照并选择当前快照。
- 将粘贴的 Apollo key/value 文本导入为新的加密快照。
- 浏览配置，默认掩码敏感值。
- 搜索配置 key 和可见值。
- 读取、添加、更新、删除单个条目。
- 对比两份快照，展示新增、删除、变更。
- 明确确认后才导出快照。

AES 工具、直接 reveal、持久操作历史、向外部 AI 发送数据均不在范围内。界面可使用安全差异的表述，但此版本不调用外部模型。

## 产品形态

采用安静的 Claude 风格快照工作区，而非密集企业后台：

- 白色侧栏包含紧凑产品标识、导入、仅会话内保存且带时间戳的最近工作、活动快照列表，以及底部本地工作区身份。最近工作刷新后清空，不存入浏览器或磁盘。
- 紧凑标题栏标识当前上下文，如 `Configuration workspace / prod`。
- 主画布打开当前快照，以简洁衬线任务标题和本地加密/敏感掩码提示开场。
- 当前环境行显示快照名、总条目数、敏感条目数、最后更新时间及本地加密状态。
- 可搜索配置表紧接环境行，是视觉重点，默认隐藏敏感值。
- 表格下方显示上下文对比面板，无需换页就能理解所选环境。
- 右侧下一步区域直达对比、单 key 编辑、导出，以及后续版本的安全 AI 摘要和 AES 工具。
- 所选快照就是活动上下文，操作后返回同一上下文，不迫使用户回全局菜单。

视觉沿用 Claude 浅色主题：白色侧栏、暖白纸面、深炭文字；珊瑚色仅用于产品标识、活动导航、环境标识和变更；绿色圆点加文字表示加密状态。衬线展示标题、低对比边框、克制的文字操作、紧凑顶栏、宽松阅读空间及精确悬停状态保持平静清晰。

配置表使用带图标的搜索、等宽 key/value、右对齐值、很淡的行分隔及轻微悬停。敏感值显示掩码点与小长度标签，不用彩色徽章；差异为带符号前缀的紧凑行。只借鉴 Claude 的语气和排版，不模仿聊天记录、不复用 Claude 素材，也不声称集成 Claude。

## 架构

新增 `ui` 子命令，在可配置临时端口启动只绑定 `127.0.0.1` 的 HTTP 服务、打开浏览器，进程退出时停止。默认不得绑定局域网接口。

服务是 Apollo 包的薄适配，不绕过该包直接读写或解密快照文件。CLI 可以重构共享应用层 helper，但其契约保持不变。

首版把静态 HTML/CSS/浏览器 JavaScript 嵌入 Go 二进制，保留单二进制、无运行时依赖的模型。浏览器只请求同一 loopback origin 的 JSON 端点。

## 数据与安全规则

- 快照值继续按当时方式 AES-256-GCM 加密落盘。
- 沿用快照密钥解析流程；无密钥时显示初始化指引，不暴露快照值。
- 浏览、列表、对比端点掩码敏感条目。可返回 key、敏感标记、存在性及长度；掩码项不得带明文或可解密密文。
- 首版不提供 reveal。
- 敏感值只通过专用编辑表单更新，输入框醒目标敏感且不预填。
- 导出是用户主动的本地下载/复制流程，确认框说明含明文配置。
- API 使用 `Cache-Control: no-store`，UI 不把快照值写入 localStorage/sessionStorage/浏览器日志。
- 校验快照标识，UI/CLI 共享名称规则以防路径穿越。

## 主要流程

### 打开与浏览

1. 用户运行 `vaulty-keeper ui`。
2. 浏览器打开工作区，侧栏列出快照。
3. 选择快照，画布进入对应上下文。
4. 显示元数据、可搜索 key/value 列表和掩码敏感条目。
5. 非敏感项可显示/编辑值；敏感项只显示元数据和替换操作。

### 导入

1. 从侧栏或当前快照上下文选择导入。
2. 收集快照名、可选 Apollo App ID 和粘贴文本。
3. 服务端用现有解析器解析，在写入前返回警告。
4. 用户确认后，加密并保存新快照。
5. 激活新快照，显示条目数及解析警告。

### 对比

1. 从活动快照上下文发起对比。
2. UI 选择另一份快照。
3. 服务端本地解密、比较值，返回安全结果。
4. 画布渲染紧凑差异面板：普通值可见；敏感项只显示掩码元数据和变化状态。

### 导出

1. 从活动快照上下文发起导出。
2. 确认框说明将生成本地明文。
3. 确认后服务端返回 no-store 文本下载；UI 不内联展示完整导出。

## 错误处理

- JSON 错误、名称非法、密钥不可用、快照缺失、导入格式错误、解密失败都返回结构化错误码与用户提示。
- 导入校验失败不创建或覆盖快照。
- 编辑/删除失败不改变原快照。
- 错误后保留当前选择，在主画布显示可重试的内联提示。

## 测试

- 包测试覆盖名称校验、安全视图投影、敏感掩码、导入预览警告、对比序列化和 no-store 头。
- HTTP 测试覆盖 loopback 默认值、输入校验、错误响应，以及列表/对比 JSON 不含敏感明文。
- 现有 Apollo 存储、解析器、AES、CLI 测试保持通过。
- 人工检查拟打开 UI、导入样本、编辑普通/敏感 key、对比并确认导出流程；这是计划要求，不是已执行证据。

## 非目标与后续

首版不实现 MCP、外部 AI 调用、AES UI、密钥轮换、操作历史、多用户或远程托管。待安全 Web UI 边界验证后，后续版本可增加 `safe-json` 导出和用户主动发起的外部 AI 交接。
