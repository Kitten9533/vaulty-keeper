## 目标与边界

为 MongoDB 8 增加固定单端点、普通用户名/密码认证的隧道。客户端获得连接专属隧道 token，不获得注册的后端凭据。接入现有加密连接存储、逐连接监听、CLI 与 Web UI，不改变 PostgreSQL/MySQL/Redis 行为。

客户端以虚拟用户 `vaulty` 认证，专属 token 是 SCRAM-SHA-256 密码，`authSource=admin`。前后端认证相互独立。后端使用注册的用户名/密码及 SCRAM-SHA-256 或 SCRAM-SHA-1；认证库优先级为显式 `authSource`、URL 数据库、`admin`。URL 省略数据库时，业务命令默认库为 `test`，但默认认证库不是 `test`。

客户端 URI 包含 `directConnection=true&retryWrites=false`。MongoDB 使用专属 token，不沿用其他协议的全局 bridge token 兜底。后端角色限制数据访问及写权限，代理额外限制命令。应注册最小权限业务账号，不需要写入时优先只读账号。

## 架构

```text
原生客户端
  -> 固定代理端点：虚拟 hello + token SCRAM-SHA-256
  -> 有界消息分帧、命令策略、命名空间与游标检查
  -> 独立后端 SCRAM、按配置启用并验证 TLS
  -> 注册的 MongoDB 8 端点
  <- 重建控制回包 / 保留业务文档
```

使用现有 `github.com/xdg-go/scram` 和 `go.mongodb.org/mongo-driver/v2` v2.9.0 的公开 BSON 包。禁止导入驱动 `x/*`、内部认证/线协议包，也不使用完整客户端作为隧道引擎。MongoDB 认证后仍须持续按帧和命令处理，不能像其他协议一样直接进入原始字节 `splice`。

分帧校验长度、BSON、请求/响应 ID、标志位和文档序列。支持 OP_MSG 及建立连接所需的有限旧式 hello，不支持通用旧式查询。转发前拒绝压缩、exhaust 和无需响应的消息。BSON 解码前限制深度为 100，未认证消息上限 1 MiB，完整帧上限 48,000,000 字节。上游批量写使用 type-1 文档序列。限制读写及认证耗时；畸形客户端不能触发无界分配，也不能让负载进入错误文本。

经过检查的 hello 字段包括 `backpressure: "2"`、`maxTimeMS`、普通 `lsid` 和 `$readPreference`。固定副本集前端发布虚拟 `setName: "vaulty"`，不发布真实主机列表/副本集名。仅在请求机制发现时返回前端 SCRAM-SHA-256。共享准入上限为 128 个连接，包括已建立和监控 socket。

注册 URL 的完整白名单与默认值维护在[指南](../../mongodb-tunnel-guide.zh-CN.md#注册-url)。TLS 必须验证证书与主机名，握手失败不得改为明文重试或关闭验证。`replicaSet` 只校验预期副本集名称，不进行发现/故障转移。当前 `connectTimeoutMS` 还限制每次上游命令耗时；调整语义时必须同步两种语言的指南与测试。

## 支持范围

支持常见 `find`、`count`、`distinct`、需要服务端写入确认的 `insert`/`update`/`delete`、`findAndModify`、只读聚合、游标和普通逻辑会话 ID。这是经过审查的命令字段和操作符子集，不代表支持这些命令的所有选项。为普通客户端导航重建有限的 ping/版本及数据库/集合/索引列表。

不支持事务、可重试写入、不要求服务端写入确认的写入（`w:0`）、压缩、SRV/多 seed、拓扑故障转移、外部认证、完整管理和诊断自省。不承诺完整 `mongosh`、原生 GUI 或驱动功能兼容性。

默认拒绝的策略递归校验命令字段、阶段、表达式和引用命名空间，包括嵌套 `$lookup`、`$unionWith` 与 `$facet`。禁止业务访问 `admin`、`local`、`config` 和 `system.*`；前端在 `admin` 认证不等于可以读取其数据。拒绝 `explain`、包括嵌套在内的 `$collStats` 等元数据阶段、`$$USER_ROLES`、服务端 JavaScript 执行及未经审查的视图。业务字面量不按表达式解析。

编排层在转发前验证每个引用命名空间都是普通集合，包括聚合嵌套来源；只检查语法无法发现视图隐藏的 pipeline。因此后端账号需要相关业务库的 `listCollections` 权限。已有命名空间必须为 `collection` 类型，排除视图和时序集合。只有元数据检查成功后，不存在的命名空间才可通过普通 CRUD 读取/创建；元数据被拒绝或无法确认时拒绝操作。可信并发 DDL 仍在保证之外。

## 回包与游标

从带类型的白名单重建 hello/认证/控制回包和已知错误结构。前端认证/控制回包及代理日志不得回显后端用户名、密码、主机名、拓扑、原始 URL、后端错误字符串或未经审查的诊断字段。重建顶层错误、`writeErrors` 与 `writeConcernError`；业务结果文档和字面量不做脱敏改写，保留 BSON 类型与嵌套字段。

游标归属范围为注册目标 + 已认证 token 身份 + 逻辑会话，并记录命名空间和原始命令类型。客户端连接池可在同一范围内换 socket 继续游标。拒绝跨目标/token/会话使用游标；不能只按 TCP socket 或数字游标 ID 记录归属。记录游标是否来自 `listCollections` 或 `listIndexes`：后续所有 `getMore` 批次必须沿用原始元数据 schema，不能进入业务文档原样通过路径。处理耗尽、`killCursors`、会话结束及清理，避免无限保留过期归属。

当前调用方在重建 `getMore` 时传入记录的原始命令。每个注册目标/token 范围最多 1,024 个游标，共享状态最多 16,384 个，会话归属单独检查；30 分钟未使用的记录过期。

## 安全与生命周期

- 前端是明文传输加 SCRAM 认证，仅用于 localhost 或隔离可信网络；上游 TLS 不会加密客户端到代理的链路。
- 可信 DBA 改变集合/视图定义，包括检查与使用之间的竞争，不在保证内。仍需后端权限和运维控制。
- 业务文档已含有的秘密不在保证内。这是凭据代管和受限命令访问，不是通用数据脱敏。
- 上游 MongoDB 审计/诊断日志不由代理脱敏。
- 同用户读取宿主密钥/存储不在隔离保证内。应让 agent 运行在无法接触这些文件或密钥的隔离域。
- `db regen` 改变新连接的认证，不撤回既有会话已接受的凭据。`db off` 在同步后关闭监听，不承诺终止已建立会话。二者都不能描述成即时会话撤销。
